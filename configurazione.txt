# Opzioni di "configure" della build di FFmpeg usata da Eclipsis: Windows 64 bit, statica,
# LGPL versione 3 (--enable-version3; niente --enable-gpl, niente --enable-nonfree).
# La versione 3 perche' e' compatibile con le licenze dei brevetti dei codec (sez. 11
# della GPL 3): il sorgente corrispondente e' pubblico in ogni release.
# Una opzione per riga; le righe che cominciano con # sono commenti.
--enable-version3
--disable-debug
--disable-doc
--disable-autodetect
--disable-network
--disable-devices
--enable-indev=lavfi
--disable-hwaccels
# D3D11 serve a compilare l'encoder h264_mf: in FFmpeg 8.1 libavcodec/mfenc.c usa i tipi
# D3D11 anche quando D3D11VA e' spento (solo l'include e' condizionato). Le decodifiche
# hardware restano spente (--disable-hwaccels); d3d11.dll si carica solo se serve.
--enable-d3d11va
--enable-w32threads
--enable-mediafoundation
--enable-zlib
--enable-sdl2
--enable-libass
--enable-libzimg
--enable-libdav1d
# Codificatori: solo quelli che il programma usa. H.264 e AAC sono quelli di Windows
# (Media Foundation), che non sono dentro gli eseguibili. (11/11/2026, v8.1-2) anche
# pcm_f32le (il controllo del silenzio iniziale del motore e l'equalizzazione automatica
# leggono l'audio in float) e pgm (la scelta del fotogramma piu' nitido).
--disable-encoders
--enable-encoder=h264_mf,aac_mf,pcm_s16le,pcm_f32le,pgm,png,mjpeg,rawvideo,wrapped_avframe
# Decodificatori: l'AAC lo decodifica Windows (aac_mf, vedi sorgenti/mfdec.c); il
# decodificatore AAC di FFmpeg non c'e'. Niente VVC. (11/11/2026) Anche l'H.264 lo decodifica
# Windows (h264_mf, vedi sorgenti/mfvdec.c): il decodificatore H.264 di FFmpeg non c'e'; il
# parser h264 e il filtro h264_mp4toannexb restano (li usano i demuxer e h264_mf).
--disable-decoder=aac,aac_fixed,aac_latm,vvc,h264
--enable-decoder=aac_mf,h264_mf
# File con licenza GPL che configure non lega a --enable-gpl.
--disable-filter=perlin,codecview
