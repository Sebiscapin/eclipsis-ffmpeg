# Librerie esterne che il linker puo' mettere dentro gli eseguibili: arrivano gia' compilate
# nell'immagine Docker di BtbN/FFmpeg-Builds. librerie.sh ne raccoglie il sorgente e gli
# avvisi di licenza; se il linker usa una libreria che qui non c'e', la compilazione si
# ferma (va aggiunta con la sua licenza).
# Colonne:
#   1. nomi della libreria per il linker (-l), separati da virgole; "-" = sempre presente
#   2. nome dello script di BtbN in scripts.d (senza il numero davanti)
#   3. licenza
#   4. "sorgente" (sorgente e avviso) o "avviso" (solo l'avviso: parti della toolchain di
#      BtbN, lo stadio "base", escluse dal sorgente corrispondente come "System Libraries",
#      GPL 3 sez. 1)
#   5. (facoltativa) file di licenza oltre a COPYING*, LICENSE*, COPYRIGHT*, NOTICE* della radice
